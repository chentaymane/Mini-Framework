Hdo.loop / Hdo.batch

One Hdo.loop() drives the render loop. Every frame the ball position is written to the store with Hdo.batch(), so the game store notifies once per frame — the HUD (mounted with a select) and the board both see one cheap re-render.

HUD subscribes to { fps, playing } only; spam the buttons below (they set bumps, which the HUD ignores) and the HUD text stays still.
